Job Application Tracker — Reference Repositories
===============================================

Overview
--------
This document lists high-quality GitHub repositories and resources to use as references when building a Job Application Tracker backend with FastAPI, PostgreSQL, SQLAlchemy, JWT authentication, file uploads, and Docker deployment. Use the focused examples for domain logic, the templates for production-ready structure, and curated lists for additional tools and patterns.

Primary References
------------------

1) AmilGael/job-tracker-api
   URL: https://github.com/AmilGael/job-tracker-api
   Highlights:
   - Focused job-application tracker built with FastAPI
   - Modular routers for applications, companies, interviews
   - SQLAlchemy models and Alembic migrations
   - CRUD endpoints, filtering, Docker + docker-compose
   - Good for domain logic and project layout specific to job tracking

2) tiangolo/full-stack-fastapi-template
   URL: https://github.com/tiangolo/full-stack-fastapi-template
   Highlights:
   - Production-ready FastAPI backend template
   - Includes JWT-based authentication and example file upload patterns
   - Dockerfile and docker-compose orchestration
   - Optional React frontend (can be omitted or used as reference)
   - Excellent for configuration management, deployment, and project structure

Supplementary Repos (features & examples)
-----------------------------------------

3) Sebastiandev/FastAPI-JWT-Auth
   URL: https://github.com/Sebastiandev/FastAPI-JWT-Auth
   Purpose: Clear examples of JWT authentication implementation with FastAPI.

4) Kludex/fastapi-tips
   URL: https://github.com/Kludex/fastapi-tips
   Purpose: Best-practice snippets and small examples (including file uploads).

5) BetaZetaDev/task-manager-fastapi
   URL: https://github.com/BetaZetaDev/task-manager-fastapi
   Purpose: Full example app with JWT, SQLAlchemy, PostgreSQL, Docker; useful CRUD patterns for task-like resources (adaptable to applications/interviews).

How to use these references
---------------------------
- Start with AmilGael/job-tracker-api for domain-specific endpoints and schema ideas.
- Use tiangolo/full-stack-fastapi-template as the core project scaffold and deployment reference.
- Copy authentication and file-upload patterns from focused repos (Sebastiandev, Kludex).
- Consult awesome-fastapi for community-recommended tools, middleware, testing helpers, and deployment strategies.
