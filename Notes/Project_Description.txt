# Project Title

Job Application Tracker

--------------------------------------------------------------------------------

# Project Overview

The Job Application Tracker is a full-stack web application that helps job seekers organize, monitor, and manage their entire placement and job application journey. Instead of maintaining spreadsheets or notes, users can track every application, interview, coding assessment, offer, and rejection from one centralized dashboard.

The application focuses on backend development, authentication, database design, REST APIs, and deployment, making it an excellent portfolio project for Software Engineering and Python Backend Developer roles.

--------------------------------------------------------------------------------

# Problem Statement

Students often apply to dozens or even hundreds of companies during placement season.

After a few weeks they usually forget:

• Which companies they applied to
• Which resume they uploaded
• OA dates
• Interview schedules
• Current application status
• Salary offered
• HR contact details

Most students manage everything using Excel sheets or handwritten notes.

This application solves that problem.

Developed a full-stack Job Application Tracker using FastAPI and PostgreSQL to help users manage job applications, interviews, online assessments, and resume versions. Implemented JWT authentication, CRUD APIs, file uploads, analytics dashboard, search and filtering, and deployed the application using Docker and cloud hosting.
